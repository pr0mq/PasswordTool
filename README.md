# Password Utility (Генератор и чекер паролей)

Простая консольная утилита на Python для генерации ультра-надёжных паролей и проверки их стойкости к взлому.

##Фичи:
- Генерация пароля заданной длины (гарантирует наличие букв разного регистра, цифр и знаков).
- Анализ пароля по 5 критериям безопасности.
- Интерактивное консольное меню с защитой от неправильного ввода.

##ак запустить:
1. Установите Python 3.
2. Скачайте файл `password_tool.py`.
3. Запустите в терминале: `python password_tool.py`
